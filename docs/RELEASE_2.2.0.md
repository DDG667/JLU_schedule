# JLU_schedule v2.2.0（Android）

Android 正式版，`versionCode=6`，最低支持 Android 8.0（API 26）。

## 本次更新

- 新增应用内更新：国内站点与 GitHub 双镜像，签名清单校验，APK 哈希、包名、版本号和正式证书校验；支持断点续传和镜像故障转移。
- 新增工具页和绩点计算器，支持从教务系统导入成绩；完善课程时间冲突展示。
- 改进校园账号登录和教务会话续期稳定性。
- 修复自动更新在断网后可能延迟重新检查、Debug 包误提示正式版更新等问题。
- 设置第一周日期时明确按周一计算；选择周中日期会先显示实际保存的周一日期，并反馈保存结果。

首次从 v1.2 升级需要手动下载安装本版；以后可在应用的“设置 → 检查更新”中更新。Android 安装界面仍需用户确认。请保留原有应用，直接覆盖安装以保留本地数据。

下载地址：[GitHub Release APK](https://github.com/JFyuhong/JLU_schedule/releases/download/v2.2.0/JLU_schedule.apk)。国内镜像目前受域名备案或接入备案阻断，暂不可稳定使用；完成备案并从外部网络验证后恢复。
