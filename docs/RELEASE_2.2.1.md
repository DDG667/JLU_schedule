# JLU_schedule v2.2.1（Android）

Android 正式版，`versionCode=7`，最低支持 Android 8.0（API 26）。

## 本次更新

- 课表详情新增“从当前课表删除课程”，支持手动添加和教务导入的课程；删除前会确认。重新覆盖导入课表时，被删除的教务课程可能再次出现。
- 修复“我的考试安排”和“学业完成查询”原网页 404，入口改为教务门户实际跳转地址。
- 考试同步区分“教务暂未发布考程”和“未能读取教务数据”，读取失败时保留已有考试。
- 修复同版本检查更新时另一更新源不可用会误报失败；设置页底部随实际安装版本显示。
